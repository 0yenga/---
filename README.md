# Лабораторная работа №1

## Задача 1. Списки. Стеки. Очереди

Программа получает последовательность пар символов `(a, b)`. Пара означает, что символ `a` предшествует символу `b`.

Программа проверяет два свойства порядка:

- **полнота** — любые два использованных символа можно сравнить по порядку предшествования;
- **противоречивость** — существует цикл, из-за которого некоторый символ предшествует сам себе через цепочку связей.

Для решения задачи пары представлены в виде ориентированного графа. Символы являются вершинами, а отношение предшествования — направленными рёбрами. Для проверки используются переходы по графу между всеми вершинами.

## Требования

- Node.js версии 18 или новее;
- дополнительных пакетов не требуется.

## Запуск

Сначала нужно указать количество пар `N`, затем записать по одной паре в каждой следующей строке.

```text
3
a b
b c
a c
```

Допускается также запись пар со скобками и запятой:

```text
3
(a, b)
(b, c)
(a, c)
```

Запуск из терминала:

```bash
npm start < input.txt
```

или:

```bash
node src/index.js < input.txt
```

Пример результата:

```text
Количество пар: 3
Использованные символы: a, b, c
Порядок является полным: да
Порядок является противоречивым: нет
```

## Проверка

Для запуска автоматических тестов используется встроенный тестовый модуль Node.js:

```bash
npm test
```

## Структура проекта

```text
src/index.js          — чтение входных данных и вывод результата
src/precedence.js     — построение графа и проверка порядка
test/precedence.test.js — тесты основных случаев
```
